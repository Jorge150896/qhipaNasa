# Componentes 3D compartidos

Punto de partida: [guía de reutilización](../../../../../docs/development/reusable-3d.md).

Importar los componentes directamente por archivo. `PlanetSurface`, `StationModel`, `ShuttleExteriorModel` y `SpaceBackdrop` permiten componer visores sin importar features de misión. `ShuttleModel` conserva el interior modular y `MissionScene` coordina el visor de misión. Mantener recursos locales, atribuciones, liberación de texturas, controles HTML y portal independiente.
