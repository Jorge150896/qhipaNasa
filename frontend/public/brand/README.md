# Recursos de Qhipa Pacha

El retrato oficial de Nami vive en `frontend/src/presentation/shared/tumi/TumiTechPortrait.tsx`. Su diseño y secuencia se redibujaron a partir de «WhatsApp GIF 2026-11-15 at 19.52.43.gif», aportado por el usuario, de 312 × 312 píxeles y 16 fotogramas. Las capas vectoriales conservan la transparencia, la cabeza flotante, el casco dorado y el visor turquesa. El GIF se utilizó como referencia de diseño y movimiento. El material aportado conserva su procedencia original.
